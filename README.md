# Bunker — МДК.04.01

Браузерная многопользовательская игра по предметной области МДК.04.01.

## Статус

- Исходные правила и каталог карточек: подготовлены.
- Игровая система: спроектирована; часть процедур требует утверждения владельцем.
- Техническая архитектура: GitHub Pages + Supabase (free tier), подлежит проверке на целевых сетях.
- Визуальные ресурсы: 180 PNG, 6 категорий по 30 изображений.

## Категории карточек

| ID | Категория | Количество |
|---|---|---:|
| roles | Роли (синие) | 30 |
| skills | Навыки (зелёные) | 30 |
| baggage | Багаж (оранжевые) | 30 |
| vulnerabilities | Уязвимости (алые) | 30 |
| crises | Кризисы (фиолетовые) | 30 |
| actions | Действия (золотые) | 30 |

## Структура ресурсов

После загрузки PNG ожидается следующая структура:

```text
public/
  assets/
    cards/
      roles/
      skills/
      baggage/
      vulnerabilities/
      crises/
      actions/
      manifest.json
      manifest.csv
```

Оригинальные имена файлов, экспортированные из Figma, сохранять. Сопоставление выполнять по стабильному `card_id`, а не по тексту имени файла.

## Документация

- `docs/01_Game_Rules.md` — исходные правила и каталог 180 карточек.
- `docs/02_Game_System.md` — модель цифровой игры и открытые вопросы.
- `docs/03_Technical_Specification.md` — техническое задание.

## Важные ограничения

1. Не придумывать и не менять игровые правила без утверждения владельца.
2. Не публиковать Supabase `service_role` key, пароли, токены и другие секреты.
3. Публичный репозиторий означает, что его исходники и загруженные изображения доступны всем.
4. Персональные данные игроков не хранить в GitHub.
5. До разработки полной игровой логики согласовать открытые вопросы из документа игровой системы.

## Разработка

Предполагаемый стек: React, TypeScript, Vite, Supabase PostgreSQL/RPC/RLS/Realtime.
